Spotify

Spotify koppel je één keer in het Hub-dashboard (bij 🎵 Muziek bedienen). Alle schermen tonen dan het nummer van dat account, met songtekst en "Hierna".

Spotify koppelen

Optioneel: dan staat Hierna: nummer uit je Spotify-wachtrij onder de artiest.

  1. Ga naar developer.spotify.com/dashboard en kies Create app.
  2. Zet bij Redirect URIs precies en vink Web API aan.
  3. Plak de Client ID hieronder.

Let op: Spotify accepteert alleen https://-adressen, of http://127.0.0.1. Open SpotiParty via HTTPS (bijv. Nabu Casa) of op de PC met serve.py.

Spotify Jam

Start een Jam in Spotify, zet Gasten mogen afspelen bedienen uit, kies Uitnodigen → Link kopiëren en plak hem hier. Vrienden scannen de code op het scherm.

SpotiParty Hub

Met de Hub stuur je meldingen, een pauze-aftelklok en de gasten-wifi naar al je schermen. De desktop-app en de Raspberry Pi starten hem vanzelf; open het dashboard op http://<die-computer>:8770.
