# SpotiParty web

De webversie van SpotiParty voor de PC en voor Home Assistant: `index.html`, `party.js` en `qr.js`. Er is geen
build-stap en er worden geen bibliotheken gebruikt. `serve.py` en `start.cmd` starten hem op de PC.

De installatie staat in de README van het project: [op de PC](../README.md#-webapp-op-de-pc) en
[in Home Assistant](../README.md#-home-assistant).
