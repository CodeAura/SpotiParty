# Een Spotify Jam starten

Met een **Jam** zetten je vrienden nummers in jouw wachtrij, vanaf hun eigen telefoon. SpotiParty zet de uitnodiging als QR-code in beeld, zodat iedereen in de kamer met een camera kan meedoen.

{% hint style="info" %}
Om een Jam te **starten** heb je **Spotify Premium** nodig. Vrienden met een gratis account kunnen wel meedoen en nummers toevoegen. ([Spotify Support: Start or join a Jam](https://support.spotify.com/us/article/jam/))
{% endhint %}

## Zo start je een Jam

{% stepper %}
{% step %}
### Zet muziek aan

Open Spotify op je telefoon en laat de muziek spelen op je tv, PC of speaker.
{% endstep %}

{% step %}
### Start de Jam

Tik op het **apparaat-icoon** of op de **drie puntjes** bij een nummer of playlist en kies **Start een Jam**.
{% endstep %}

{% step %}
### Zet de rechten van gasten goed

Open de **instellingen van de Jam** en zet de optie uit waarmee gasten bepalen wat er speelt (in de Nederlandse app heet die iets als _Gasten mogen afspelen bedienen_). Dan kunnen vrienden alleen nummers toevoegen: niet overslaan, pauzeren of het volume veranderen.

De precieze naam van deze optie verschilt per versie van de Spotify-app. Zoek naar de schakelaar over wat gasten mogen bedienen.
{% endstep %}

{% step %}
### Kopieer de link

Tik op **Uitnodigen → Link kopiëren**. Je krijgt een link die begint met `https://spotify.link/`.
{% endstep %}

{% step %}
### Plak de link in SpotiParty

Waar je de link plakt, hangt af van je versie:

* **Android TV:** scan de code **Jam instellen** op de tv met je telefoon en plak de link daar. Zie [Stap 5: Openen en Jam koppelen](../android-tv/stap-5-jam-koppelen.md).
* **PC:** in het instellingenscherm (toets **S** of ⚙). Zie Instellen op de PC.
* **Home Assistant:** klik in de kaart en druk op **S**, of klik op ⚙.
{% endstep %}
{% endstepper %}

## Als de Jam stopt

Stopt de Jam, dan werkt de oude link niet meer. De QR-code op het scherm leidt dan naar een verlopen uitnodiging. Start een nieuwe Jam en plak de nieuwe link. Op de tv haal je de oude code eerst weg met **↻ Nieuwe Jam** (twee keer OK).

## Wat kunnen gasten wel en niet?

| Gasten kunnen                               | Gasten kunnen niet (als je de optie uit hebt gezet) |
| ------------------------------------------- | --------------------------------------------------- |
| Nummers zoeken en toevoegen aan de wachtrij | Pauzeren of overslaan                               |
| De wachtrij bekijken                        | Het volume veranderen                               |
