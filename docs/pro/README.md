# SpotiParty Pro

Het feestscherm zelf (hoes, songtekst, Jam-QR, **Hierna**) is en blijft **gratis**. Met **SpotiParty Pro** bestuur je al je schermen vanaf één plek:

| Pro-functie | Wat het doet |
| --- | --- |
| **Admin-dashboard** | Alle SpotiParty-schermen in huis op één pagina, ook op je telefoon: welke online zijn en wat er speelt. |
| **Meldingen** | Typ een bericht (“De pizza's zijn er! 🍕”) en het verschijnt groot bovenaan op de schermen die je kiest. |
| **Korte pauze** | Een grote aftelklok van het aantal minuten dat je kiest. Als de tijd om is, staat er dat het feest verdergaat. |
| **Gasten-wifi** | Een QR-code naast de Jam-code: gasten scannen en zijn verbonden met je gastennetwerk. |
| **Home Assistant volledig scherm** | De SpotiParty-kaart over heel Home Assistant, zonder zijbalk en kop. Zie [Volledig scherm in Home Assistant](../home-assistant/volledig-scherm.md). |

## Kopen

Koop Pro op [spotiparty.netlify.app](https://spotiparty.netlify.app/#prijzen). Direct na de betaling krijg je een mail met je **licentiecode**: een lange code die begint met `SPOTI-`.

{% hint style="info" %}
De code staat op jouw naam. Het dashboard en de Home Assistant-kaart controleren hem zonder internet; er wordt niets naar ons gestuurd.
{% endhint %}

## Activeren

1. Open het [Hub-dashboard](hub-dashboard.md).
2. Ga naar **🔑 Licentie**, plak de hele code en kies **Activeren**.
3. Bovenaan staat nu **Pro · jouw naam**. Alle schermen die met de Hub verbonden zijn, krijgen de Pro-functies.

Je activeert Pro dus één keer, op de Hub. Voor de Home Assistant-kaart op volledig scherm zet je dezelfde code in de kaart.
