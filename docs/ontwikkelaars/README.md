# Voor ontwikkelaars

SpotiParty heeft bewust geen afhankelijkheden: de Android-apps gebruiken geen enkele bibliotheek, de webversie heeft geen build-stap en de PC-server is pure Python. In dit hoofdstuk lees je hoe het project in elkaar zit, hoe je de desktop-app zelf bouwt en hoe een release ontstaat.
